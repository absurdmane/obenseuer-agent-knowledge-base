# Loading screen, hints, event cameras, blackout, death
Scope: the loading screen and fades, the hint overlay, the card-game tutorial queue, camera helpers (intro trigger, event camera, shake, main-menu camera), blackout and wake-up, sleep event names, the death entry. Sleep-event effects are in player-movement-tiredness-sleep.md, prison in police-crime.md, the death gate in combat-npcs.md. The intro sequence controller and scene data (which triggers use which values) are not covered.
Status: code-only
Related: [levels.md](levels.md), [saves.md](saves.md), [ui-options-input.md](ui-options-input.md), [player-movement-tiredness-sleep.md](player-movement-tiredness-sleep.md), [combat-npcs.md](combat-npcs.md), [minigames.md](minigames.md)

## Where it lives [code]

- `LoadingScreen` (singleton, DontDestroyOnLoad; `loadingSreenHints`: title, background sprite reference, text, `area`). `HintOverlay` (static registry plus panel), `HintContext` (feeds it), `HintContent`/`HintSection`. `TutorialMessageManager` (plain class built by `CardGameTutorial`). `IntroCameraTrigger`, `IntroStart`, `EventCamera`, `CameraShake`, `CameraShakeTarget`, `MainMenuCameraPosition`. `BlackoutTrigger` (scene component) and `BlackoutController` (singleton, wake-up). `SleepEventController` (enum `SleepEvents`). `Death.PlayerDeath`.

## How it works [code]

- `LoadingScreen.LoadLevel(scene, soundsMuted, isWhiteScreen, manualFade, changeHint)` picks the hint, enables the canvas and loads asynchronously; the fade raises alpha 0.05 per frame and drives the mixer parameters "Load", "LoadScreen", "PauseMenu" (unless `manualFade`). It reuses a scene preloaded by `LoadSceneAsyncTrigger.currentAsyncScenes` (sets `allowSceneActivation`), else `SceneManager.LoadSceneAsync`; the bar uses progress/0.9. After loading it sets `Time.timeScale = 1` and `AudioListener.pause = false` (so a pause set across a load is cleared), sets `LevelLoadDone`, waits while `TimeOfDayAzure.updateTimeDisabled`, then fades out. The next hint is preloaded through Addressables (random entry of `hintList`); a failed preload keeps the previous text and background. `Fade(...)` is the non-scene fade; `ChangeMirgrationStatus` shows a migration panel with a counter.
- `HintOverlay.Show(owner, content, priority, startHidden)` replaces an entry with the same owner; the shown entry is the highest priority, then the newest; destroyed owners are pruned. Visibility: suppressed hides; else the per-entry override; else the global `HintsEnabled` (`PlayerPrefs`, default on). The "Hints" key toggles the entry's override if it has one, else the global flag and raises `HintsToggled`; ignored while a key is being rebound. `HintContext` shows on `OnEnable` and hides (removes) on `OnDisable`; `{key:Name}` tokens are replaced by bound key names.
- `TutorialMessageManager`: a queue of messages with `onShow`/`onClosed`; `ShowNextTutorial` does not advance while the event waiter waits for a card play or turn, and raises `Finished` at the end.
- Cameras: `IntroCameraTrigger` (a collider tagged MainCamera increments `IntroStart.number`); `EventCamera` on enable disables controls (`GameController.ControlsDisabled(owner)`), `PlayerCamera.DisableCamera` and `PauseMenu.DisableSave(owner)`, and reverses all on disable; `CameraShake.Shake(duration, amount)` offsets the main camera and registered `CameraShakeTarget`s (callers: `Minitrain`, `PajatsoGameplay`, `PlayerStatsHealth` damage, `SMVEffects`, `Env_Shake`), `AddTarget` uses `Dictionary.Add` (adding a transform twice throws) and a restarted shake does not restore targets first; `MainMenuCameraPosition` sets camera Z from the aspect ratio and lerps between menu positions in 0.5 s.
- Blackout: `BlackoutTrigger.Sequence` disables controls, fades to black, fires `onBeforeTeleport`, stands the player up, teleports to `teleportTarget`, fires `onBlackout` and `onAfterTeleport`, steals money (OC/RM percent with optional cap) and random item stacks (skipping what `SleepEventController.AllowedToRemove` refuses), holds `blackScreenDuration` in real time, then either changes level (`SaveController.ChangeLevel` with a scheduled wake-up in `BlackoutController`) or plays the ground pose and `FinishWakeUp` (or waits for a manual `TriggerWakeUp` when `autoWakeUp` is false), then `onWakeUp`. `WakeUpAnimationType`: None, OnGround, OnGround2.
- `SleepEvents` enum: None, Wakeup, StealRandomItems, StealMoney, StealOS, StealRM, StealMostValuableItem, Steal, Beat, Arrest, Quarantine, CoveredWithJunk, InfectSMV, GetCaughtFromCrime, Nightmare, CrazyNeighbor, Invoice. `Event_Kidnap` exists with no enum value.
- `Death.PlayerDeath(reason)` runs once (guard `dead`; where it resets was not checked): death sounds, `PlayerStats.ShowDeathEffect`, `PauseMenu.PausemenuDeath`, `DeathMessage`; a radiation death triggers achievement `RADIATION_DEATH`.
